# Guides

Task-shaped walkthroughs, each ending with something running on your machine. They read well in
order, but any one of them stands alone.

<div class="pl-cards" markdown>

<div class="pl-card" markdown>
<span class="pl-card__kicker">Guide 1</span>
### [Build your first task](first-plugin.md)
Build a task plugin from an empty directory — task, environment, agent, rollout, config — and train
on it.
</div>

<div class="pl-card" markdown>
<span class="pl-card__kicker">Guide 2</span>
### [Multi-agent workflows](multi-agent.md)

tree.

</div>

<div class="pl-card" markdown>
<span class="pl-card__kicker">Guide 4</span>
### [Inspect rollouts](inspect-rollouts.md)
Replay an episode turn by turn in the TUI to find the step where a reward went wrong.
</div>

<div class="pl-card" markdown>

Swap in your own environment, agent, dataset, rollout, reward or workflow — and package it as a
plugin that lives in your own repository.
</div>

<div class="pl-card" markdown>

Move from one node to many, and keep long runs alive.
</div>
